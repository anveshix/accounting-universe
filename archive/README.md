# archive/

Old files kept for reference only. Nothing here is built, tested or deployed.

- `legacy-html/` — snapshots of the single-file app taken before later rewrites. The live legacy app is `index.html` (served at `/legacy/`).
- `legacy-tests/` — broken scripts (`test.js`, `test_init.js`, `check_syntax.js`) that predate the workspace test suite. They do not parse or run; use `npm run check` instead.

Delete these once you are sure nothing needs them; Git history keeps them either way.
